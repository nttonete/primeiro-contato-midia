# Primeiro Contato: mídia

Imagens públicas dos posts do Instagram [@primeirocontatoadv](https://instagram.com/primeirocontatoadv), usadas pelo Metricool para agendar as publicações. Os arquivos-fonte e as legendas ficam no repositório privado `primeiro-contato`, na pasta `instagram/`.

## Na Hora

A pasta `na-hora/` guarda as imagens e vídeos públicos do Instagram [@atendenahora](https://instagram.com/atendenahora), do Na Hora. As fontes e as legendas ficam no repositório privado `primeiro-contato`, na pasta `na-hora/instagram/`.
